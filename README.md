# Data Storage – Frontend

## Overview

This is the frontend application for the EduCraft Education Management System.

It provides a user interface for interacting with the EduCraft backend API and demonstrating system functionality.

Backend repository:  
https://github.com/Zileena6/datalagring-linda-leminaho

---

## Purpose

The frontend allows users to:

- View data from the backend
- Create and manage records
- Demonstrate backend functionality

The frontend focuses on presenting data and sending requests to the backend API.

---

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS

---

## Running the Project

### Requirements

- Node.js 18 or later
- npm

---

### Clone repository

```
git clone https://github.com/Zileena6/datalagring-frontend-linda-leminaho.git
cd datalagring-frontend-linda-leminaho
```

---

### Install dependencies

```
npm install
```

---

### Run development server

```
npm run dev
```

Open:

```
http://localhost:3000
```

---

## Backend Dependency

The backend must be running before using the frontend.

Start backend:

```
dotnet run --project EduCraft.Presentation
```

---

## Assignment Context

This frontend exists to demonstrate and test backend functionality.

The primary focus of the assignment is backend development and database integration.
